# SaaS Subscription Landing Page — HTML & CSS

A modern SaaS subscription landing page built with **pure HTML & CSS** — no JavaScript frameworks, no dependencies.

## Features

- Clean and modern SaaS/product UI design
- Fully responsive — works on mobile, tablet, and desktop
- Pricing & Plans section (Basic, Standard, Premium)
- FAQ / Accordion section
- Testimonials section
- Stats section (1M+ customers, 93% satisfaction, 4.9 rating)
- No JavaScript frameworks or libraries

## Sections

| Section | Description |
|---|---|
| Navbar | Logo, nav links, and CTA button |
| Hero | Headline, subtext, and dual CTA buttons |
| Features | Project management, Time tracking, Mobile app |
| Getting Started | Onboarding highlight with app mockup |
| Stats | Key numbers and metrics |
| How it Works | 3-step process (Create, Assign, Done) |
| Testimonials | Two customer quote cards |
| Pricing & Plans | Basic ($29), Standard ($49), Premium ($99) |
| FAQ | 4 expandable questions |
| Footer | Multi-column links + branding |
